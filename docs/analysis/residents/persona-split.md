# Persona split: goals.md and identity.md

Each persona's `memory/` folder now has two parts. The `identity.md` file ends with a `## What draws <name>` section. The `goals.md` file holds one first-person starting line.

goals.md text moved verbatim into identity.md under 'What draws <name>'; goals.md now holds a first-person starting line the character owns.
