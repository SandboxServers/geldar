## HC-26c: supervisor-side sheet reading and the proof the model never sees it

- **Branch** `scriptorium/hc-26c-sheet-proof`. **Depends on** HC-26b, HC-19 (the real spawn path in `deps.ts`).
- **Files (may edit).** `packages/instinct/src/sheetfile.ts` (new: `readSheetFile(dir, uid)`), `packages/instinct/src/sheetfile.test.ts` (new), `packages/instinct/src/run.ts` (call `readSheetFile` in place of the plain read), `packages/supervisor/src/blind.test.ts` (new), `tests/image/player-compose.test.ts` (cases), `tests/image/sheet-blind.test.ts` (new, Docker; skipped locally, runs in CI). **Must not edit** `childEnv`, `PASS_THROUGH`, or any launcher file.
- **Steps.**

A link, a non-regular file, any group or other mode bit, an owner other than `uid` (POSIX only), or a size over 4096 bytes gives `null`. `run` reports `pass` with `sheet_invalid`. Then `parseSheet`. On Windows the mode and owner checks are skipped and their tests skip.
  2. `run.ts` calls `readSheetFile`. Nothing else in `run.ts` changes.
- **Tests and revert checks.**

  - `run with an invalid sheet reports sheet_invalid and no model run` (revert: throw).
  - `blind: childEnv has no key matching /SHEET|INSTINCT/i and no value containing the sentinel text, for claude, chatgpt and local (when HC-08 is merged)` (revert: add `GELDAR_INSTINCT` to `PASS_THROUGH`; fails).
  - `the sheet sits at <stateDir>/instinct/sheet.json and nowhere under the workspace; a fixture run's captured argv and cwd hold neither the sentinel, the name sheet.json, nor the state path, except the prompt path` (revert: pass the sheet path in argv; fails).
  - `compose: the player service mounts the workspace at /player only; the keeper mounts the supervisor state read-only; neither mentions sheet` (revert: add a sheet bind mount; fails).
  - `image (Linux CI, Docker): as uid 1000 and as uid 1002 cat of instinct/sheet.json is denied; as uid 1001 it succeeds` (revert: chmod 0644; the denial case fails).
  - `chatgpt with sanity on: the loop process receives exactly the five SanityParams keys on descriptor 4 and none of aggression, curiosity, cleverness, law, good, op_modes` (this is the HC-23b case; keep it here as the proof's last case, skipped until HC-23b merges).

## HC-46b: agent positions and the roster reader (kit half)

- **Branch** `scriptorium/hc-46b-agent-pos-roster`. **Depends on** HC-46a (merged), HC-26b (roster delivery). Geldar's `players-cli roster export --out <path>` (on geldar `origin/main`) is the producer; this card does not call it.
- **Files (may edit).** `packages/instinct/src/observe.ts`, `observe.test.ts`, `packages/instinct/src/social/roster.ts` (new), `packages/instinct/src/social/roster.test.ts` (new), the worknote. **Must not edit** anything else.
- **Exact shapes.**
  ```ts
  // observe.ts: agents gains an optional position, nothing else
  agents: { name: string; distance: number | null; pos?: { x: number; y: number; z: number } }[];
  // roster.ts: names to life ids from the supervisor volume. The observation never carries an id.
  export function readRoster(stateDir: string): Map<string, string>; // <stateDir>/roster.json
  ```
- **Steps.**
  1. `agentsOf` reuses `posOf` (HC-46a) and adds `pos` only when all three numbers are finite. Existing `{name, distance}` fixtures parse as before.
  2. `readRoster` reads `<stateDir>/roster.json`. A missing, unreadable, non-regular or over-16-KiB file gives an empty map. The JSON must be one object of `name: lifeId`. Keep an entry only when the name has 1 to 40 characters, no control characters, and the id passes `SAFE_ID`. Drop every other entry. Never throw. Two names mapped to one id are both kept.
  3. Only the HC-30a adapter calls `readRoster`. The map is never passed into an observation.
- **Tests and revert checks.**
  - `an agent with x, y, z parses a pos; an agent without parses as before` (revert: drop the parse; fails).
  - `an agent with a missing z has no pos` (revert: default z to 0).
  - `readRoster: a missing file, an oversize file, a bad id and a bad name each give an empty map or drop the entry` (revert: return the raw object; fails).
  - `a valid roster maps a name to its id` (revert: return an empty map).
  - `an observation never carries an id: a world reply with an id field on an agent yields no id string anywhere in the parsed result` (revert: copy the id through; fails).
- **Checks.** `./scriptorium.ps1 pnpm exec vitest run packages/instinct/src/observe.test.ts packages/instinct/src/social/roster.test.ts`; lint; typecheck; `check:repo`.
- **Size** 22k. **Commit subject** `feat(instinct): optional agent position and a supervisor-side name roster (HC-46b)`.
- **Agent-visible text** none in this card. The position field is already approved by 0289 item 6 for the geldar side; its wording is not this card's.
- **Inactive**: both inputs are optional; no roster means an empty map and no `pos` means today's output.
