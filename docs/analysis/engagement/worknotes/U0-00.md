## Queries

```sql
-- capture
SELECT count(), countIf(arrayExists(e -> e LIKE '%tool_arguments%', events)), min(timestamp), max(timestamp)
FROM signoz_traces.signoz_index_v3 WHERE name = 'mcp.tool_call';

-- shapes
WITH JSONExtractString(JSONExtractRaw(arrayFirst(e -> e LIKE '%tool_arguments%', events), 'attributeMap'), 'geldar.content.tool_arguments') AS args
SELECT multiIf(JSONHas(a,'item') AND JSONHas(a,'at'),'item+at', JSONHas(a,'item') AND JSONHas(a,'entity'),'item+entity', JSONHas(a,'item'),'item alone', JSONHas(a,'at'),'at, no item', JSONHas(a,'entity'),'entity, no item','nothing') AS shape,
       match(JSONExtractString(a,'item'), '_(sword|axe)$') AS weapon, count() AS n
FROM signoz_traces.signoz_index_v3 ARRAY JOIN JSONExtractArrayRaw(args, 'actions') AS a
WHERE name='mcp.tool_call' AND attributes_string['gen_ai.tool.name']='act' AND JSONExtractString(a,'do')='use'
GROUP BY shape, weapon ORDER BY weapon DESC, n DESC;
```

The per-item, example and phrase queries follow the same pattern (item and shape grouping; `groupArray(3)` for examples; `match(lower(args), ...)` per tool).
