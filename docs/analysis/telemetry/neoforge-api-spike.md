# NeoForge API spike (PT-N5)

Target loader: NeoForge 26.1.2 (build 126), Java 25. Read-only spike: no code, no node contact.

Method: the `neoforged/NeoForge` repository, branch `26.1.x`, files fetched as raw text on 2026-11-17. `gradle.properties` on that branch pins Minecraft 26.1.2 and Fancy Mod Loader 11.0.15. The branch does not hold vanilla source, only patches (`patches/**/*.patch`). So a vanilla accessor is VERIFIED only where a patch line or context line shows it. Everything else stays UNVERIFIED. The build number (126) is not in the branch files and is taken from the plan.

Paths below are relative to the repository root. `EV` = `src/main/java/net/neoforged/neoforge/event/`. All classes are on the game bus (`NeoForge.EVENT_BUS`) unless noted.

## 2. Additional items seen (not asked, relevant to PT-N7/N8)

- `PlayerEvent.PlayerLoggedInEvent`, `PlayerLoggedOutEvent`, `PlayerRespawnEvent`, `PlayerChangedDimensionEvent`, `ItemCraftedEvent` (`getCrafting()`), `ItemSmeltedEvent` (`getSmelting()`) are nested in `EV/entity/player/PlayerEvent.java`. Logged in and out are posted through `EventHooks.firePlayerLoggedIn` and `firePlayerLoggedOut` in the `PlayerList` patch.
- `ItemTossEvent` (`EV/entity/item/`), `ItemEntityPickupEvent`, `PlayerDestroyItemEvent`, `AttackEntityEvent`, `CriticalHitEvent`, `PlayerContainerEvent`, `AdvancementEvent`, `ItemFishedEvent`, `PlayerXpEvent` exist in `EV/entity/player/` (names only; accessors not read).
- Cancel flag: `CommandEvent`, `LivingIncomingDamageEvent`, `Start/Stop/Tick` use events, the interact events, `BabyEntitySpawnEvent`, `AnimalTameEvent`, `PermissionsChangedEvent`, `ExplosionEvent.Start` all `implements ICancellableEvent`. `LivingDamageEvent.Pre/Post`, `Finish`, `TradeWithVillagerEvent`, `PlayerWakeUpEvent` and `ExplosionEvent.Detonate` are not cancellable. This confirms the plan's risk 1.2 item 3 for these events; `isCanceled()` is called on the posted event in the `Commands` patch.
- Not-cancellable events must not carry a `cancelled` attribute (set it false or omit it).
