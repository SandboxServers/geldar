## Wave 5 conventions (every wave 5 packet)

- **Contract first.** Every message between the Body, the Mind and the Thinker, and every model output shape, is a schema in `contract/`. Regenerate the code; never hand-edit generated files.
- **Fan-out packets build against the P0-20 and P0-21 interfaces and fakes and never edit those files.** If an interface is wrong, write an "interface request" section in your report (the exact change and why) and work around it locally. P0-32 applies the requests.
- **Unit tests use fakes only.** No Ollama, NATS, Postgres or Minecraft in `./geldar.ps1 check` or CI. Integration tests are `*.it.test.ts`, skipped unless `GELDAR_IT=1` (those that need Ollama also `GELDAR_OLLAMA=1`). Live cases are `golem/test/live/*.live.test.ts`. All are written in the packet and run by the orchestrator at the wave end. Live cases print the state they saw in every failure message (diagnostics first) and use the standard `resetBot` step (wave 4 retro A5).
- **Phase 0 runs the Mind, the Thinker and Adam's Body as Node processes on the host** (see Q2). Every address is loopback: NATS `127.0.0.1:4222`, Postgres `127.0.0.1:5432`, Ollama `127.0.0.1:11434`, the Mind's Thinker socket `127.0.0.1:7410`. Secrets are read from `compose/secrets/*.txt`.
- **In-world text is untrusted** (threat model section 5, decision 0034). Speech, sign text and player names reach a prompt only as JSON-escaped strings inside a fixed, labelled "quoted world text" section of the user message, never in the system message. The output validator is the control: strict schema, a Phase 0 allow-list, bounds checks. A failure is rejected and recorded, never repaired silently.
- **Prompt templates in `prompts/` are immutable once used.** A change is a new `vN` file. Every thought records `prompt_template_version`, `schema_version`, `mind_version`, `body_version` and `model_config`.
- **No new SQL migration** (D-P0-11: the live volume has no migration runner). If a column is missing, file an interface request; the orchestrator decides.
- Files stay under 500 lines; no `utils`/`helpers`. Briefs have at most about 12 items. At 80 turns a coder commits what is done and lists what remains in its report. Coders edit only inside their worktree.

## P0-25: Thinker hub: the local Appendix H server and the `ModelClient`

- **Depends on** P0-21. Branch `phase0/p0-25-thinker-hub`, worktree `p0-25`. Commit: `feat(animus): add the local Thinker hub and the model client that dispatches jobs to it`.
- **Spec:** Appendix H (the rules the Gateway enforces), threat model sections 3 and 4 (identity from the transport, completion ownership, size limits, strict schemas).
