## Deviations from the spec

- Imports for the P0-02 block are inside the block, not at the top of `index.ts`. This keeps the edits inside the marked block, so the parallel packets only conflict on their own blocks. Biome accepts this.
- Strict-mode Ajv needs `properties` in each `required`-only `anyOf`/`oneOf` branch (`intent`, `actions`, `skill_id`, `text`). The schema does this.
- `vote.proposal_id` uses `^pr_[0-9A-HJKMNP-TV-Z]{26}$` (a ULID after the prefix), not the bare `^pr_` from the packet. This matches the other IDs.
- `skill_id` in `write_book` is a plain string, since the packet gives no pattern.
- Bounds not given in the packet: `give`, `offer`, `deposit` and `withdraw` counts are 1–64, matching `ItemStack`. `build` block offsets are unbounded integers.
- `arguments`, `checkpoint`, `use_skill.args` and `propose.value` are free-form. Those objects set `additionalProperties: true` with a description, as the snapshot's event payload does.
- Biome formatting was applied to the three hand-written files (`biome check --write`) to get `pnpm lint` green.
