## Reconnect flake

The drain test (`drains: closes, then reconnects after the given delay`) waited for `connections === 2` and then asserted two hello frames. The server counts a connection before the second hello frame arrives, so the count could be 1. The fix adds `until` on the second hello frame before the count assertion. The assertions are unchanged.
