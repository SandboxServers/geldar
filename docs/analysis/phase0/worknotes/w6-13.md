## Modules and interfaces

Package `tools/adam-run` (`@geldar/adam-run`, private, ESM). Depends on `yaml` 2.9.1 and the workspace package
`@geldar/adam-report` (the report step is reached through the `Reporter` port; the package is not imported yet).

- `src/abort.ts`: the pure abort rules. `evaluateAbort(history, nowMs, criteria)` returns the first fired rule
  or null; `sustained` is the window check. Thresholds come from `abort-criteria.json`. Tests in `abort.test.ts`.
- `src/ports.ts`: the ports, with no adapter code. `Clock`, `FileStore` (read, write, append, lines),
  `Processes` (list, with `ProcessView`), `Supervisor` (`up`, `restartStack`, `killBody`, `stop(service)`),
  `Sampler` (`observe(): Observation`), `Reporter` (`reportRun(runId)`, the W6-12 report step, a separate port),
  `Runner` (exec with an argument array). `runPaths(runDir)` builds the manifest, status and abort paths with
  `path.posix`. Services: `body`, `animus`, `lantern-local`.
- `src/manifest.ts`: profile to life id (`32b` ag_adam_01, `8b` ag_adam_02, `smoke` ag_smoke_01), `readPins`
  from `shards/phase0.yaml`, `buildManifest`, `writeManifest` (`posix.join`), `sha256Hex`. The no-secrets canary is
  in `manifest.test.ts`.
- `src/status-log.ts`: one JSON line per simulated minute (`statusLine`, `minuteOf`), harness lines without a
  sample (`eventOnlyLine`), `appendStatus`. The store has no rewrite for this file.
- `src/preconditions.ts`: `checkPreconditions(facts)` returns every missing item with what to do (benchmark gate,
  clean tree, model pins, life id, fresh-volume marker for 8B, loaded models limited to the profile model and the
  embedding model).
- `src/safe-stop.ts`: `ownership(process, runStartedAtMs)` (`owned`, `other`, `unverifiable`, the verifyProcess
  pattern), `safeStop(deps, input)`: stops `STOP_ORDER` = lantern-local, animus, body; signals an owned leftover
  gracefully, then forces it once; a no-orphan check over the process list (`pass`, `fail`, `unverifiable`); writes
  `abort.json` and a `safe_stop` status line; a second call is a no-op. Tests in `safe-stop.test.ts`.
- `src/sequence.ts`: `runSequence(deps, input)`. Precheck (a refused run writes and starts nothing), manifest,
  `supervisor.up`, then one sample a minute: status line, abort rules, planned restart with a recovery check
  (`restart_not_recovered`), Body kill once at an active intent (the kill latch stays set), the Body reconnect check
  (`body_not_recovered`), end at the target duration. Any abort runs `safeStop`, then the report, then an `abort`
  line. Tests in `sequence.test.ts` (20, including the 30-minute smoke and the 3-hour 32b run).
- `test/fakes.ts`: fake clock, file store, processes, supervisor, sampler, reporter and preflight, for the tests.

## Deviations from the card

- Stop order is lantern-local, animus, body (the reverse of the start order in `tools/adam-cli/src/procs.ts`), as
  in the earlier worknote.
- The Reporter is a separate port, not a call inside the sequence, so the report step can be replaced in tests.
- `startBody` is removed. The supervisor restarts the Body with the stack; the sequence never starts it alone.
- Two abort rules are added beyond the card: `body_not_recovered` (the Body does not reconnect after the kill) and
  `error` (an `adam up`, restart, sampler or kill call fails). Both abort through the same safe stop and report path.
- Path normalisation: run paths and the manifest path use `path.posix` in one place, so the Windows and Linux
  runs compare the same keys.
