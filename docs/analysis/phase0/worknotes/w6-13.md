# W6-13 worknotes: the adam-run protocol (part a, harness core)

Status: partial. Part a is not finished; the items under "Left" are not written yet.

## What exists

Package `tools/adam-run` (`@geldar/adam-run`, private, ESM). Depends on `yaml` 2.9.1 and the workspace
package `@geldar/adam-report` (for the report step; not yet imported).

- `src/abort.ts` (WIP from the earlier session): the pure abort rules, `evaluateAbort` and `sustained`,
  with thresholds read from `abort-criteria.json`. Tests in `src/abort.test.ts` (21).
- `src/ports.ts`: the ports (clock, file store with read/write/append, processes, supervisor, sampler and
  the observation shape). Real adapters are not written.
- `src/manifest.ts`: profile to life id (`32b` ag_adam_01, `8b` ag_adam_02, `smoke` ag_smoke_01), `readPins`
  from `shards/phase0.yaml`, `buildManifest`, `writeManifest`, `sha256Hex`. Tests in `manifest.test.ts`,
  including the no-secrets canary.
- `src/status-log.ts`: one JSON line per minute (`statusLine`, `appendStatus`); the store has no rewrite
  for this file. Tests in `status-log.test.ts` (append twice keeps the first line byte-identical).
- `src/preconditions.ts`: `checkPreconditions(facts)` returns every missing item with what to do.
  Benchmark gate (`benchmark-gate.json`: sha equal to HEAD, result pass, 20 TPS at 100%), clean tree,
  model pins against Ollama digests, life id per profile, fresh-volume marker for 8B, loaded models
  limited to the profile model and the embedding model. Tests in `preconditions.test.ts`.
