## 4. Soft-cap exception: `threshold/mcp-mock/src/server.ts` stays unsplit

`threshold/mcp-mock/src/server.ts` is 565 lines. It is above the 500-line soft cap and under the 700-line hard cap, so it stays as it is. The reason: the guard test `threshold/mcp-mock/src/sim/books.test.ts` allows `node:http` imports only in `server.ts`. Splitting the file would need the guard to be loosened for a refactor, and the guard is not loosened for a refactor. This is the recorded exception; the `check` soft-cap warning for it is expected.
