## Diagnosis

1. **Thoughts did not stop because of Ollama, the tier, VRAM or the thinker link.** Ollama is loaded (`qwen3:8b`, 100% GPU, 6.3 GB), its server log has no error, and the only request after 14:12:42 is the keep-alive ping. Lantern-local logged no disconnect, and its last job completed at 14:12:42.811. 24 GB VRAM is not the cause: only 8b was resident.
2. **The Mind went quiet after the reflex_danger thought at 14:12:42.826.** Idle wakes come from the attention controller's 60 s watchdog (`idleWatchdogMs`). They are armed only in `thoughtSettled` when no intent is active. Neither an idle wake nor a fallback wake reached a model call. The fallback is `fallback_wakeup_ticks: 6000` at `tick_rate: 20`, which is 300 s, so it was due about 14:17:42. It produced nothing.
3. **Most likely location:** a cycle that started (`thoughtStarted`, so `inFlight` true) and never reached `thoughtSettled`, so every later wake was held as `coalesced_in_flight`. Candidates are `requestSnapshotWithRetry` (`animus/src/loop/snapshot-retry.ts`, which retries with a budget), `callWaitingForThinker`, or `links.settled()` in `thinking-loop.ts:92`. None logs when it waits, so the logs cannot separate them. **Not proven in this packet.** The next step is a `thought_started` log line and a hang timer in `ThinkingLoop.handle`, run against a real smoke.
4. **The 10-minute rule is not what is wrong.** It fired after 9 minutes and 11 seconds of silence (14:12:42 to 14:23:30 is 10 min 48 s), so the rule did its job. The thought stall was real. A 300 s fallback plus a 600 s keep-alive would not on its own exceed 10 minutes, so the rule's threshold is not too tight for this run. I did not change `abort-criteria.json`.
