# W6-10: the Thought Stream page

## What exists

- `glass/public/index.html` and `glass/public/app.css`: the page. The banner says it is read-only
  and for human observers only. There are filters for agent, outcome, template version, time range
  and keyword, a pause button, a "Load older" button and a detail panel.
- `glass/public/app.js`: the page script (`type="module"`). It loads the agents, then the first page
  of thoughts from `/api/thoughts`, opens `/api/stream` with the reconnecting, pausable client from
  `glass/src/render-stream.ts`, and draws every row with `glass/src/render-view.ts`.
- `glass/src/render-model.ts`: the pure view model (filters, the 2000-row cap, the 4000-character
  clip, invisible-character markers, backoff). `glass/src/render-view.ts`: the DOM builder, which
  sets text only, with `textContent`.
- `glass/src/http.ts`: the static route. It serves `/`, `/app.css`, `/app.js` and the three render
  modules as `/js/render-*.ts`, type-stripped and sent as `text/javascript`. Only `GET` is allowed
  (`405` with `Allow: GET` otherwise). A path that is not in the table gets `404`.
- Tests: `glass/src/render-*.test.ts`, `glass/src/http.test.ts` (route, traversal, exact CSP) and
  `glass/src/page-safety.test.ts` (forbidden APIs under `glass/public` and the render modules, and
  an inline-free `index.html`).

## How to view it

Glass has no compose service yet. `./geldar.ps1 glass up` arrives with W6-13. Until then, start
Glass by hand from the repository root with the variables in `glass/README.md` set (Postgres
reachable, the `geldar_glass` password file in place):

```powershell
./geldar.ps1 pnpm --filter @geldar/glass start
```

Then open `http://127.0.0.1:8787/`. Without a database the page says `Could not load thoughts.`

## Deviations from the card

- `GET /` now serves the page. The earlier W6-09 expectation (404 at `/`) is changed on purpose.
- The CSP on every response is `default-src 'none'; script-src 'self'; style-src 'self';
  connect-src 'self'; img-src 'none'; base-uri 'none'; form-action 'none'; frame-ancestors 'none'`.
  `glass/README.md` still shows the shorter W6-09 string; W6-11 owns the README.
- `glass/src/http.ts` and `glass/src/http.test.ts` are changed, although the card names only
  `glass/public/**` and `glass/src/render-*.ts`. The brief directed the static route.
- Pause keeps the stream open and holds new thoughts in a buffer capped at 2000. The stream
  client's own pause is not used.
- The template-version and keyword filters apply to the loaded rows only. The API has no template
  filter. The agent, outcome and time-range filters reload the first page from the API.
- The per-agent view is the agent filter.
- The detail panel shows receipts only when the thought carries an `action_id`. The thought row
  does not carry one today, so the receipts list stays empty.

## Not covered by a test

- `app.js` is not run in a DOM test. The tests check its sources statically and check the served
