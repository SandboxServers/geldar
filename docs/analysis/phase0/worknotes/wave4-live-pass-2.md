# Wave 4 live pass 2 (orchestrator, from the w4-fix-1 worktree: wave4 head + live-test fixes and diagnostics)

Live lane: 6 failures (previous pass 5). L1 (integer coordinates) is fixed. Findings:

- L4 (REAL BODY BUG, found) `wood-to-stone-tools` step 6: inventory at failure is `stick x16` and no planks, `detail: {"missing":{"oak_planks":3}}`. Cause: `craft stick count 4` crafted 16 sticks (4 crafts of 4) and used all 8 planks. `craft.ts` computes `times = ceil(count / bookYield(bot, item))` from `unlockedDisplays(bot, item.id)[0]`; with every recipe granted (Geldar-Core grants all recipes on join), `stick` has more than one display (planks make 4, bamboo make 1) and the first one in the book may be the bamboo display (yield 1), so `times` is 4, but the working display (planks) makes 4 per craft. The first display tried is not necessarily the one that works. Fix: do not decide `times` from a guess of the yield; craft once, read the real gain from the inventory (or the result slot count), then compute how many more crafts are needed, never overshoot `ceil(count / observed_yield)`; test with two displays of different yields in the fakes (`craft-table.fakes.ts`). This also explains why the failure appears since the plugin grants every recipe, and why it reproduces at the wave 3 base commit.
- L3 (panic burrow) the new diagnostic shows `{"result":"failed","detail":"could not dig the pocket"} at 994.39 200.00 804.51` with a stone_bricks floor and dirt around (3x3x3 dump in the log). Consistent with review finding A1 (dig by block name picks the wrong block; the floor is stone_bricks, the walls dirt). Coder X fixes with an exact-cell dig.
- L5 `reflex-combat.live.test.ts` (3 tests: armed bot kills a zombie, unarmed bot flees, a bot at 4 health retreats): the reflex never fired (`fired` false). They passed in pass 1 (night / dawn, world time about 23340) and fail now: the world is in full daylight, so a summoned zombie burns (and no hostile attacks). The tests must not depend on the time of day: set the time to night (`time set midnight` via the test control, restore afterwards in `finally`) or protect the zombie from the sun (a helmet, or summon inside a roofed arena slot), and assert with a message that prints the entities near the bot.
