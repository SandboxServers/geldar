## Open Body issue and a data point for the 32B run

These two points are not owner items with an ID. They come from W6-26 items 4 and 5 and are recorded in [worknotes/w6-26.md](worknotes/w6-26.md).

- **Abandoned reflex action with no receipt (open, Body).** In the smoke run, a `panic_burrow` reflex was abandoned with no suitable block, every 10 s from 16:24:53 to 16:34:14. Action `ac_01M72NSJ0QRF428BB0TT8S7VZV` ended `abandoned` with no prepared receipt. Decision 0020 requires exactly one final receipt, `committed` or `aborted`, for every action, and spec section 10 asks for it on every action. So the receipts criterion fails, correctly. The fix belongs in the Body: write one `aborted` receipt when an action is abandoned, with a `detail` of at most 256 characters. The report does not change. Owner question: is this a blocker for the 32B run, or does the run go ahead and the gap stays on the record?
- **The 8B model died within six minutes (data point).** In the smoke life, the death came at 16:26:14, about six minutes after the body started at 16:20:07. Read this as evidence about the model and the survival rule, not as a verdict on the 32B run. The 32B run has a longer life and a stronger model, so it is not the same test. The owner should weigh it against O-2 and O-13 before the 32B run starts.
