# GX-06 worknote: source on the sovereign call (world side)

Status: ADVISORY. Part 1 (contract) and part 2 (MCP wiring) are in. The `source` class stays ADVISORY until the kit's denial test (HC-19, kit side HC-L1 by scriptorium-orchestrator) passes. Nothing is on by default: no connection is an instinct connection unless `GELDAR_MCP_INSTINCT_KEY_FILE` names a usable key file, and none is set in the repo or in any shipped shard config.

## Part 2 (MCP): what is in

- `threshold/mcp/src/http/instinct-key.ts`: `loadInstinctKey(text)` (one trailing LF/CRLF removed; empty is off; under 32 bytes is refused), `sameKey(presented, key)` (sha256 of both sides, then `crypto.timingSafeEqual`), `connectionSource(req, key)` (reads `rawHeaders`; a repeated, absent, wrong or different-length `X-Geldar-Instinct-Key` is `model`; no key loaded is `model`).
- `threshold/mcp/src/config.ts`: optional `instinctKeyFile` from `GELDAR_MCP_INSTINCT_KEY_FILE` (unset or empty: no instinct class).
- `threshold/mcp/src/main.ts`: `instinctKeyOf(path, readSecret, log)` reads the file as the pepper is read. Unset or empty is silent. An unreadable file logs `instinct_key_unreadable`; a short key logs `instinct_key_refused`. The key, the file text and the path are never logged.
- `threshold/mcp/src/http/front.ts`: `instinctKey` option. `connectionSource` is read by the mock only after the bearer check has passed, when the session is made.
- `threshold/mcp-mock/src/server.ts`: `connectionSource` option; `createSession(playerId, signal, { source })` with the class as an optional third argument (default model). `threshold/mcp-mock/src/registry.ts`: `ToolContext.source`.
- `threshold/mcp/src/world-session.ts` and `world.ts`: the class reaches `callerOf`, which sets `source` only for `instinct`. `threshold/mcp/src/tools/act.ts` (`callPayload`) records it.
- `tools/act.ts` is unchanged in this part: tool input never sets `source`.

## Tests

- `threshold/mcp/src/instinct-door.test.ts` (through `createFrontDoor`, `createWorldSession` and `createWorld` on loopback): a right key on an authenticated connection is `instinct`; a wrong key, an empty key, a key one byte short or long, and a repeated header are `model`; no key loaded is `model`; an unauthenticated connection is refused (401) with or without the key; an instinct act records `source: 'instinct'`, a model act records no `source`; every MCP tool, under an instinct session, returns no text containing the key, the header name or a `"source"` actor field; the log never holds the key or the header value, including on a wrong key; the start-up key read logs one constant line and never the key; no source file under `threshold/mcp/src` assigns `operator`.
- `instinct-key.test.ts` and `act.test.ts` as before.
- Revert checks (committed state, one line each, restored byte for byte): `callerOf` without the `source` line fails "an act on the instinct connection records source instinct; a model act records none"; `front.ts` with `connectionSource: () => 'model'` fails "a right key on an authenticated connection gives the instinct class".
