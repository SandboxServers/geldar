# GX-06 worknote: source on the sovereign call (world side)

Status: part 1 of 2 done (contract). Part 2 (MCP) is partly done: the pure pieces and the act.ts field are in; the wiring is NOT. The `source` class is ADVISORY until the kit's denial test passes, and it is OFF everywhere: no connection is an instinct connection yet.

## Part 2 (MCP): what changed

- `threshold/mcp/src/http/instinct-key.ts` (new): `loadInstinctKey(text)` (one trailing LF/CRLF removed; empty is off; under 32 bytes is refused), `sameKey(presented, key)` (sha256 of both sides, then `crypto.timingSafeEqual`), `connectionSource(req, key)` (reads `rawHeaders`; a repeated, absent, wrong or different-length `X-Geldar-Instinct-Key` is `model`; no key loaded is `model`).
- `threshold/mcp/src/tools/act.ts`: `Caller` has an optional `source?: 'instinct'`; `callPayload` records `source: 'instinct'` only for that value. Absent means model. Tool input never sets it.
- Tests: `instinct-key.test.ts` (prefix-equal, equal-length, longer, shorter and empty refused; the compare is spied through `vi.mock('node:crypto')`), `act.test.ts` (instinct records `source`; model records no `source` and never `operator`).
