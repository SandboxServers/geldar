## Open items (owner decisions, not applied)

1. `mine` names no position. The Body digs the nearest block of the wanted name, which can be
   another player's crop or an unripe crop nearer than the target. The program's ownership gate
   checks the cell it chose, not the block that is dug. Options: (a) an `at` on `mine` (changes the
   action schema), (b) a `goto` next to the cell plus a nearest-block guard, (c) accept the property
   as "the program only chooses cells it may touch" and record that the Body can break a nearer
   same-name crop. The fake `nearest()` in `farm.test.ts` is unchanged; the owner-skip resume test
   uses a distinct crop name per cell to avoid the ambiguity.
2. The owner of an `empty` cell is read at the air cell, not the farmland below it. A farmland
   block tilled by another player can read `own`.
3. Owners are read on a cold cache. The first step in an uncached chunk can read `unknown` and
   skip the cell for good. `start()` does not prefetch owners (no `prefetchOwners` in the card's
   import list). Owner to decide whether `start()` may await `prefetchOwners`.
4. Checkpoint shape deviates from AN-44's `FarmCheckpoint: { cells, next, harvested, sown, skipped }`.
   This program adds `replant`, `max_cells`, `skipped_owned` and `skipped_unknown`, which `resume`
   needs. AN-44 must be amended (and its validator) before merge, or the two shapes disagree.
5. The crop name of the cell being sown is not checkpointed. A resume between a harvest and its
   sow sows any carried seed, not the harvested crop's seed; a straight run would pick the matching
   seed. The resume tests use one crop per run, so this is not covered.
6. The `gated` memo is not observable with constant owners, so no test fails when it is removed.
7. The `limit` versus `done` boundary (exactly `max_cells` crops found) is not changed. Review note
   12's optional `maxCells + 1` read is not applied.
8. Commit message: the brief's exact message (`fix(golem): farm replant flag, seed match, ray-cast
   order and harvest coverage (AN-40 review fix)`) is used, not the reworded message in review
   note 10.
