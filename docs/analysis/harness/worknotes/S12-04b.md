### Finding: M7 survives

The test named `dry run writes nothing: only the planner SELECT runs` (`tools/mcp-tokens/src/adopt-apply.test.ts`, line 374) runs `player adopt-sheets` with no flags, so it is a dry run by default. It never passes `--dry-run`. The explicit `--dry-run` path is therefore not covered: with `--dry-run` set, a write would go unnoticed. The fix is a test that passes `--dry-run` alone and asserts zero writes. It is not added in this packet, so the test is not changed here.
