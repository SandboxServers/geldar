# C7-14: operator route to set a player's public camera and delayed public thoughts flags

Scope: migration 0034 adds `operator_set_player_flags(player id, public camera, thoughts delayed public)`, granted to the
operator role `geldar` only. It takes the player id, not the owner identity used by the owner routes, and writes one
`register_audit` row per call (actor `operator`, action `player.flags`).

Surfaces: `node tools/mcp-tokens/src/cli.ts player flags <player-id> --public-camera on|off --thoughts-delayed-public on|off`,
`deploy/colo-admin.sh player-flags <player-id> ...`, and the `player-flags` verb in `tools/admin/admin.sh`.

Rules: the thoughts flag keeps its 10-second window (outcome `too-soon`, exit 3, nothing changed); the camera flag has none.
Unknown and retired players exit 4. Refusals do not raise, so the audit row is kept.

(+ test), cli.ts, deploy/colo-admin.sh, tools/admin/admin.sh, docs/runbooks/mcp-tokens.md, worknotes/C7-14.md.
