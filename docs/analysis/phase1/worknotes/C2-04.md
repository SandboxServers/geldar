## Review fixes (C2-R3) and C2-07 live steps

- The client address is now set with `header_up x-geldar-client-ip {remote_host}` inside each `reverse_proxy`; the `request_header -...` strips stay.
- Every Glass `reverse_proxy` sets `header_up Host localhost`, because Glass answers 421 to any other Host. Glass routes the page (`/`, `/app.css`, `/app.js`, `/js/*`) as well as the API. `/api/stats` is no longer routed.
- Caddy validate (pinned digest above) passed for the live and the -off sets after these changes; CI runs `deploy/caddy/validate.sh` in the `compose` job.
- C2-07 live step: set `GELDAR_GLASS_TRUSTED_PROXIES` to Caddy's peer address, then check with two clients that their rate-limit buckets are separate.
- C2-07 live step: BlueMap live player markers must be off. Prove it with a request for the live players file from loopback (it must be absent or empty). If they are on, the public map shows living players in real time and bypasses the Glass delay and sovereign filter.
- C2-07 live step: open Glass as an anonymous visitor through Caddy and check the page loads (`/`, `/app.js`, `/app.css`) and `/api/thoughts` answers 200, not 421.
