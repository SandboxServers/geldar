## Deviations and decisions

1. **Playerid versus playername (ruling 2).** The register sends the agent's display name as `playerName` (wave 4 review F1). The earlier version sent the URL `ag-` player id; the supervisor keys a body by the Minecraft roster name, so every body route would have answered 500. The supervisor lowercases `playerName` (`service.ts`, `attempt`) and reads the exact-case display name from `supervisor_player_display_name` (`pg-ports.ts`, `displayName`). The register does not need to send the exact case. A display name outside `^[A-Za-z0-9_]{1,16}$` is 422 invalid with the fixed detail, with no supervisor call. Open item: none.
2. **Status 200 returns only `state`.** The supervisor's `running` and `idle` replies carry no health or hunger, so `health` and `hunger` are not supplied. They are not invented. The card's `BodyStatus` lists them; the route does not return them until the supervisor supplies them.
3. **login_name 422 carries `detail`.** The card requires the body to tell the owner that the name must be 3 to 16 letters, digits or underscore. The problem schema had `type, title, status, code` and no `detail`. Ruled (wave 4 review F8): `detail` is now an optional string in the schema (`owner-api-v1.yaml`), set through `sendProblem`. Open item: none. The supervisor's text never reaches the body (test: `login_name is 422 invalid with the fixed text, never the supervisor text`).
4. **Retry-After constants.** `QUOTA_RETRY_SECONDS = 3600` (the supervisor's hourly counter). 3600 is a floor: the owner-day cap can need up to 24 h, and the reply does not say which cap was hit. `UNAVAILABLE_RETRY_SECONDS = 30` (timeout, no responders, unreadable reply). `rate_limited` on repeat starts: at most 5 starts per 60 s per agent (`START_WINDOW_MAX`, `START_WINDOW_MS`); the wait is the seconds until the oldest start leaves the window.
5. **Supervisor `invalid` is a register bug.** A refusal `invalid` (a malformed request from the register) maps to 500 `internal`. Any reply code not in the table maps to 503 `body_unavailable`, never 200.
6. **Supervisor refusals `busy` and `error`** map to 503 `body_unavailable`.
