## Clock and timing seams

- `golem`: a file-access seam, not a clock. The packet's clock seam does not apply, because the test reads no clock. The commit is `995c75c`.
- `repo-checks`: not changed. The spawn cost cannot be faked without moving the CLI's checks into a function that takes the git reader and the clock as parameters. That is a refactor of `cli.ts` (224 lines) and is outside this packet's budget. It is the next step, and it would keep one spawn case with the 30 s bound.

## Revert-check (golem)

- Mutation: in `resolveImport`, `files.isFile(candidate)` back to `realFiles.isFile(candidate)` (the real disk).
- Result: `catches a file that imports the RCON layer, directly, dynamically or transitively` fails, because the fixture paths are not on disk. Deterministic.
- `resolves directory, .js and extensionless...` still passes under the mutation, because the real `rcon.ts` exists on disk. It is not a revert-check failure for that case.
- Restored from a backup copy; `git diff --stat` matched the committed change.
- Five consecutive runs of `golem/src/test-control.test.ts` after the restore: 26 of 26 each time.
