# C2-07a3: Glass inside the Colo network

- `GELDAR_GLASS_HOST=0.0.0.0` is accepted only with `GELDAR_IN_NETWORK_HOSTS=1`. Other non-loopback values are refused with or without the opt-in.
- `GELDAR_GLASS_PG_HOST` is now checked: `127.0.0.1` or `localhost` always, `postgres` only with the opt-in. Before this packet any value was accepted, so this is a tightening (the spec said to keep the existing strictness, which was none).
- `GELDAR_GLASS_PUBLIC_HOSTS`: exact names, lower-cased, optional port in the Host header, no wildcards. Default empty.
- Tests: `glass/src/config.test.ts`, `glass/src/guard-http.test.ts`. Revert-checks: dropping the opt-in test in `assertLoopback` fails 3 tests; dropping the list lookup in the Host check fails the allowlist test.
- Live: none.
