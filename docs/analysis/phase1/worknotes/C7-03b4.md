# C7-03b4 worknote: Body container spec mirrors golem-body

Card: [c7e-packets.md](../packets/c7e-packets.md) (added by the wave C7-2 review, pass 2, F2). Lane B (supervisor). Wave 3, after C7-03b3 merges. Migration none.

## Why the card exists

The supervisor creates a Body container with `containerBody` in `supervisor/src/docker.ts`. Today that function sets Image, User, one Env (`GELDAR_LOGIN_NAME`), Labels, limits, network, log config, CapDrop and SecurityOpt. A supervisor-created Body therefore has no NATS credentials, no Minecraft host and the image default command. It runs hardened and does nothing, and it still counts against the owner's quota. The wave ruling is that Body containers mirror the compose `golem-body` service. This card closes that gap before C7-03b2 enables the supervisor service on the node.

## golem-body reference (compose/colo.yml, read only)

The service sets the following. Items marked (card) are in the C7-03b4 card's list; items marked (extra) are in compose but not in that list and must be mirrored or stated as unset.

- Entrypoint `["node", "src/adam/main.ts"]` (card).
- User `${GELDAR_SERVICE_UID:-1000}:${GELDAR_SERVICE_UID:-1000}` (card).
- Env (card): `GELDAR_SHARD=colo`, `GELDAR_IN_NETWORK_HOSTS=1`, `GELDAR_MC_HOST=velocity`, `GELDAR_MC_PORT=25565`, `GELDAR_NATS_URL=nats://nats:4222`, `GELDAR_NATS_USER=body`, `GELDAR_NATS_PASSWORD_FILE=/run/secrets/nats-body.txt`.
- Env (extra): `GELDAR_RCON_PORT=25575` (the Body does not use RCON; the port is still set in compose), `GELDAR_TELEMETRY_URL` (unset in the container).
- Secret (card): `nats-body` mounted read-only at `/run/secrets/nats-body.txt`.
- Shard bind (card): `../shards/colo-mind.yaml` to `/opt/geldar/shards/colo.yaml`, read-only. The source is the Mind's shard file, not the budget file.
- Limits (extra): 1 CPU, memory 2048m, `memswap_limit` equal to the memory limit, 256 pids. Check these against `supervisor/src/limits.ts` before changing any constant there.
- Labels and logging (extra): the shared colo labels and log anchor.
- Network (card): `colo`. Restart policy (extra): `unless-stopped`.
- Dependency (extra): starts after `nats` is healthy. A supervisor-created container cannot express this; note it in the test or the runbook, do not fake it.

## UID drift

`supervisor/src/docker.ts` line 23 hard-codes `const BODY_USER = '1000:1000'`. Compose reads `${GELDAR_SERVICE_UID:-1000}`. The card requires the supervisor to read the same variable with the same default, so the literal must not drift from the compose default. Until that change lands, the two are only equal while the variable is unset.
