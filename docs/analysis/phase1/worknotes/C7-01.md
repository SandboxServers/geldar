# C7-01 worknote: sessions survive a restart

- Sessions moved from the register's in-memory Map to the `register_sessions` table (migration 0021), keyed by the SHA-256 of the cookie id. The id itself is never stored.
- The form CSRF token is derived from the session id with HMAC, so the table holds no copy of it.
- Sliding expiry: 30 minutes idle, capped at 12 hours from sign-in (`session-store.ts`).
- An expired or unknown session gets the expired page with 401 and a cleared cookie. A missing cookie still redirects to the start.
- A database error on lookup fails closed (401 expired page, row kept). A database error on sign-in throws, so no cookie is issued.
- Migration 0021 is the only new migration here; C7-08 uses 0022.
- The ledger, RESUME and decisions README are not edited by this packet.
