## Findings and live-step checks

- **Glass bind inside the container (blocking for live).** `glass/src/config.ts` `assertLoopback` accepts only `127.0.0.1` as `GELDAR_GLASS_HOST`. In a container a process bound to the container's loopback is not reachable through a Docker publish. Glass needs an in-container bind mode (as `GELDAR_MCP_IN_CONTAINER` in the MCP) before the publish works. `glass/` was off limits here; C2-07a1 or a Glass follow-up must add it, then set `GELDAR_GLASS_HOST`/the bind in this service.
- **Trusted proxy address.** Check on the node what peer address Glass and the MCP log for a request from Caddy (127.0.0.1 or the colo bridge gateway). If the gateway, set `GELDAR_GLASS_TRUSTED_PROXIES` and `GELDAR_MCP_TRUSTED_PROXIES` to it in the deploy env and update `public.trusted_proxies`.
