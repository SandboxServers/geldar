## Deviations

1. **Body entry point.** The card says "the Body's existing start script". `golem/package.json` has no start script; its only executable entries are `src/bench/cli.ts` (the benchmark), `src/players/main.ts` (a player body that needs a player id) and `src/adam/main.ts` (the Adam Body). The image runs `src/adam/main.ts`, the Adam Body. The card's wording about "the Body" is read as Adam's Body.
2. **Missing-credential error.** The card's error behaviour says a run without a NATS password file must exit non-zero and name the missing variable. The Body's and Mind's configuration code does not read a NATS or Postgres password file yet (`golem/src` and `animus/src` are outside this card's may-edit list; the NATS auth packet C1-06a adds it). The smoke therefore fails on the shard file first, with a one-line JSON `fatal` message naming the file. It does not print a stack trace. The image's `ENV` and `ARG` set no credential, which the tests check.
3. **Worknote path.** The brief names `docs/analysis/phase1/worknotes/P1-C1-03.md`; the card header says `C1-03.md`. The brief's name was used.
4. **Smoke scope.** The smoke ran with no secrets and no shard file, as a one-off `docker run --rm`. No shard, NATS, Postgres or Minecraft server was touched.
5. **No GHCR workflow.** The card does not name a workflow file, so none was added.
6. **Commit trailer.** The brief's commit trailer names Claude Sonnet 5.5. The session's attribution note names Claude Haiku 5.5. The brief's trailer was used, as the brief instructs.
