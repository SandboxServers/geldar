## Schema version

- `feed_version` is the const 1.

## Error shapes

- `pane_cap_reached`: the per-session pane cap is full.
- `target_not_permitted`: the login scope does not allow the target.
- `feed_unavailable`: the feed is not running, or `lakitu.enabled` is false.
- `feed_overloaded`: the Java load cap refused the frame (P1-C2b-01).

## Cap defaults

- `max_panes_per_session`: 4 (the card's proposal; owner not yet confirmed).
- `max_sections_per_frame`: 256 (proposed, owner to confirm).
- `max_updates_per_frame`: 512 (proposed, owner to confirm).
- Pane `radius_chunks`: 1 to 4 (proposed max 4).
