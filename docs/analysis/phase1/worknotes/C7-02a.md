# C7-02a worknote: player token lifecycle

Decision 0170 point 1. Migration `sql/0032_token_lifecycle.sql` (ruled in by the orchestrator; 0032 reserved for this packet).

## What changed

- `register_mint_token` (0032 replaces 0010): lifetime 90 days, was 30. Still revokes older tokens at once on a fresh mint.
- `register_renew_token(identity, player, token_id, token_hash, grace_until)`: rotates. The new token keeps the player id and lives 90 days. Each older live token ends at the earliest of its own expiry, `grace_until` and 10 minutes 1 second from now. The grace is an expiry, not a revoke, so the mcp check (`expires_at > now()`) reads it unchanged. The database caps the grace, so a caller cannot extend it.
- `register_revoke_tokens(identity, player)`: revoke-only, no replacement. Returns the number of live tokens ended.
- `register_token_info(identity, player)`: the newest live token's expiry and last use, for the account page.
- All four are SECURITY DEFINER, pinned search_path, owner-scoped by the identity hash, and refuse an unknown or banned identity and a foreign player with 42501. The register role gets EXECUTE only.

## Grace boundary

`graceEndsAt(rotatedAt)` is `rotatedAt + 10 minutes + 1 second`. The old token is usable at exactly 10:00 and refused at 10:01 (the card's "10 minutes and 1 s"). The one second is `GRACE_END_SLACK_MS` in `threshold/register/src/tokens-policy.ts`.

## TypeScript

- `threshold/register/src/tokens-policy.ts`: policy functions (expiry, renewal flag, grace end).
- `threshold/register/src/tokens-service.ts`: renew, revoke and account data, behind a `TokenStore` interface. Each action runs the admin check, then the window (skipped for an admin), then the database call, and writes exactly one audit row. A database error is audited as `error` and rethrown with no value. The new secret is returned only after the database call succeeds.
- `threshold/register/src/pg-store.ts`: `renewToken`, `revokeTokens`, `tokenInfo` over the functions above. A 42501 from the database is a refusal.
