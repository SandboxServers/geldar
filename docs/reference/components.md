# Components

One row per Geldar component, with a link to every document that covers it, cradle to grave. Use it to find the right document for a component, to see who owns it, and to see what a change to it can reach. It holds no facts of its own beyond the owner role, the README check and the neighbour check: every other cell points to the document that holds the fact.

The lifecycle columns follow the template in [plan.md section 7](../analysis/docs-library/plan.md#7-lifecycle-template). Every cell is a link or says "none, because" and why. Every link resolves (checked by script on 2026-11-16 at `1b114276`, anchors included). Links that earlier waves marked "planned" had their mark removed on 2026-11-16 once a script found each target file at `3f07a4be`; the anchors added in that pass (to [decisions-by-topic](decisions-by-topic.md), [failure-modes](../operations/failure-modes.md) and the [security](../security/README.md) pages) were matched against those pages' headings by hand.

Some linked pages are `agents-never` (marked **(a-n)**). They are operator material. Never copy or link them, or this page, into anything an agent in the world reads ([documentation style](../agents/documentation-style.md#agents-never-learn-they-are-watched)).
