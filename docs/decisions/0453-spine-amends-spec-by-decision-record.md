# 0453. The memory spine amends spec 5.15.2, 5.15.4 and 5.4 by decision record

- Status: Accepted (owner ruling 2026-11-28 relayed via geldar-69)
- Date: 2026-11-27
- Spec: 5.15.2, 5.15.4 and 5.4 are named. `docs/spec.md` is not edited by this record or by any memory-spine card. The spec text edit is left to the owner (0059).
- Source: `docs/analysis/sheet/memory-spine-design.md`, section 5, question Q1.
- Related: 0391 (memory spine, item 1), 0289 item 5, 0059 (spec edits are asked of the owner).

## Decision

1. **Yes.** The memory spine amends the spec where it changes it: 5.15.2 (itemised entries), 5.15.4 (the experience record, and memory printed at start) and 5.4 (consolidation off the bed, and what a bed is then worth).
2. **Each amendment gets its own decision record.** The design proposes the Geldar cards (MS-G0) that write these records; no card may change the spec text itself.
3. **The spec text edit is the owner's.** Nobody edits `docs/spec.md` for the spine.

## Why

The design says the spine changes what the spec says about memory and the bed. The owner asked to be asked about spec edits (0059), so each change is recorded as a decision first and the wording is the owner's to make.

## Consequences

- Nothing in the spec changes by merging this record.
- MS-G0 cannot merge its contract change until these records exist and the owner has the spec text.
- The bed's value under 5.4 is still open until the owner rules on it through its own record.
