# P0-27 attention controller

Files: `animus/src/attention/{controller,classify,coalesce,policy,timing,timing.fakes}.ts` and tests `classify.test.ts`, `controller.test.ts`.

Design: `Attention` implements `AttentionController`, takes an injected `Clock` and `Scheduler` (`ManualTiming` fake). Spacing deferral, the fallback (`fallbackWakeupTicks / tickRate` seconds from intent start, re-armed on `thoughtSettled`) and the idle settle (250 ms wait for the Body's own wake after an intent ends) are scheduler timers. `start()` emits `mind_start`. Spacing applies to every reason except `no_plan` and `mind_start` (Q8); deferred wakes are merged and emitted at the window end, never dropped. `digestSummary()` gives the per-speaker count and last three lines.

Classification rule: `addressed` = name or username as a whole word that opens or closes the line, is set off by a comma or colon, or follows `@`; a whole word elsewhere is `about_me`; then `about_my_commitments`; else `overheard`.

Revert-checks (each mutation fails at least one test): no spacing, no in-flight hold, no exemption, no fallback re-arm, idle ignoring the Body wake. The last one first survived; the test was strengthened.

## Interface requests (for P0-32)
1. `SuppressionReason` lacks `coalesced_in_flight`; the controller records `thinking` for wakes held behind a thought. Add the code (and rename or alias) if the audit wants the spec name.
2. `MindWakeReason` lacks `speech_about_my_commitments`; a commitment line is emitted as `speech_about_me` (ranked above it internally).
3. `WakeDecision.digest` is `MindEvent[]` and carries only the last three lines per speaker; the counts are available only through `Attention.digestSummary()`. Add a `digestSummary` field to the decision if the prompt needs counts.
4. No `Clock` or `Scheduler` port exists; `animus/src/attention/timing.ts` defines them locally.
5. Unknown Body wake reasons are recorded as `intent_running` and do not wake.
