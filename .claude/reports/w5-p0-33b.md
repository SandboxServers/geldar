## Deviations

- Cases live in `golem/test/live/*.live.test.ts` (the card allowed a golem-side file): golem has the fixture, RCON and the chatter, animus has no way to reach them. They run with `./geldar.ps1 pnpm --filter @geldar/golem test:live` and `GELDAR_IT=1 GELDAR_OLLAMA=1`.
- `adam-case.ts` is a second shared file (the card said one helper file per package; this one is the live scaffold and has no logic worth a unit test).
- The shard file offers no override for the life or tier, so the cases check `shards/phase0.yaml` (`mind.agent.username: ag_adam_02`, `mind.run_tier: fast`, `mind.agent.tier: fast`) and fail at once with the fix if it is not set for the 8B life. P0-33a's `--model fast` is not used (it is not in this branch).
- "Accepted plan" is read from the `intents` table (`thought_id` of a valid thought), "accepted intent" from an intent in `accepted|running|completed`; there is no plan table. Intents from earlier runs of the life are filtered out by id.
- The 30 s answer window is measured from the wake: the `speech_addressed` thought row's `at` minus its `latency_ms`.
- Injection prompts audit the first two messages of `model_input` (system and user); later messages are the corrective retry, which can echo model output.
- The hostile lines come from `animus/src/prompts/hostile-text.corpus.json` (`ignore_earlier`, `forged_closing`, `fake_json`), each prefixed `Adam, `; the case checks the corpus still holds the markers it looks for.
